⚡ Quick Start — How to Run

1

Make sure Python 3.10+ is installed

Download from https://python.org if you don't have it. During install on Windows, check "Add Python to PATH".

2

Run the starter file — one double-click

Windows: Double-click START_OMNICITYAI.bat in this folder.
Mac / Linux: Open Terminal in this folder and run:

chmod +x START_OMNICITYAI.sh ./START_OMNICITYAI.sh

⏳ First run installs packages and downloads AI model weights (~2–4 GB). This can take 5–15 minutes depending on internet speed. Subsequent launches are instant.

3

Wait for the server ready message

You'll see this line in the terminal when the backend is live:

INFO: Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
4

Open your browser and navigate to the portal

Start at the Citizen Portal — it's the entry point for the whole system.

http://localhost:8000/index.html
⚠
Do NOT open the HTML files directly by double-clicking them. They must be served through the backend at localhost:8000 — otherwise all API calls will fail and the site will show blank data.
✅
The omnicityai.db database already contains pre-registered citizens and demo reports — you don't need to register from scratch to see the system working.

🎬 Recommended Demo Flow for Judges

1

index.html → Register a new citizen

Upload any Aadhaar card image — the OCR pipeline (EasyOCR) will extract the name and ID. MTCNN crops the face, FaceNet creates an embedding. Watch the Trust Score assign automatically.

2

index.html → Log in and see the Identity Token

Enter Aadhaar last-4 digits + name. Your Trust Score (0–100), Karma points, Penalty Tier (None/Warn/Restrict/Ban), and accessible facilities appear.

3

dashboard.html → Watch the live city

Open the City Map tab. The 20×20 digital twin is running live — road colours show traffic density, signals cycle Red→Green, active incidents appear as overlays, and emergency Green Wave corridors glow when triggered.

4

dashboard.html → File a Verified Incident Report

Go to the File Report tab, upload a photo of something relevant (fire, crowd, damage). The CV pipeline will scan it and either VERIFY or REJECT the report, updating Karma live.

5

citizen_walker.html → Trigger Chhaya SOS

Navigate to any grid node. Press SOS. Watch ML-1 instantly create a Green Wave emergency corridor routing police + ambulance to your exact position. See it reflected on the dashboard map simultaneously.

🔧 Troubleshooting

?

Site shows no data / "Failed to fetch"

The backend isn't running. Make sure the terminal running START_OMNICITYAI.bat (or .sh) is still open and shows the Uvicorn message. Don't close it while using the site.

?

Port 8000 already in use

Another process is on port 8000. Kill it or change the port in backend.py (last line: port=8000) and update the URL accordingly.

?

pip install fails / permission error

Run the terminal as Administrator (Windows) or use sudo (Mac/Linux). Alternatively add --user flag to pip commands.

?

CV model features return simulated data

If heavy models (CLIP, FaceNet) fail to download on first run, the system gracefully falls back to simulation data. The rest of the platform (digital twin, trust engine, Chhaya) remains fully functional.
